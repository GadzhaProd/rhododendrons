# Фильтрация ассортимента по цвету и высоте

**Дата:** 2026-04-13  
**Страница:** `/assortiment`

## Цель

Добавить на страницу ассортимента фильтрацию продуктов по цвету и размеру (высоте), чтобы покупатель мог быстро найти подходящий рододендрон.

## Архитектура

### Разделение компонентов

- `app/assortiment/page.tsx` — остаётся server component. Сохраняет `export const metadata`. Рендерит `<Suspense>` обёртку вокруг `AssortimentClient`.
- `app/assortiment/assortiment-client.tsx` — новый client component (`"use client"`). Содержит панель фильтров и сетку продуктов.

### Состояние фильтров (URL search params)

Фильтры хранятся в URL через `useSearchParams` + `useRouter`:

- `?color=Helderrood` — фильтр по цвету (параметр может повторяться для мультиселекта)
- `?size=40–60+cm` — фильтр по размеру (параметр может повторяться)
- Пример мультиселекта: `?color=Helderrood&color=Warm+roze&size=60–80+cm`

Преимущества: ссылки можно шарить, браузерная кнопка "назад" работает.

### Логика фильтрации

- Внутри одной категории — **OR**: продукт подходит, если его цвет совпадает с **любым** выбранным цветом.
- Между категориями — **AND**: продукт должен подходить **и** по цвету, **и** по размеру одновременно.
- Фильтр по размеру: продукт проходит, если в его `sizes` есть **хоть один** размер из выбранных.
- Если фильтры не выбраны — показываются все продукты.

## UI панели фильтров

Панель размещается между заголовком страницы и сеткой продуктов.

### Структура

```
[ Kleur:  ] [Паарс-лавандel ×] [Helderrood] [Warm roze] ... (12 чипов)
[ Maat:   ] [30–40 cm] [40–60 cm] [60–80 cm] [80–100 cm] [100–120 cm] [120–140 cm]
            [ Wis filters ]         3 van 12 variëteiten
```

### Детали

- **Чипы цветов** — уникальные значения поля `color` из всех продуктов (12 вариантов), отсортированные алфавитно.
- **Чипы размеров** — уникальные значения `size.label` из всех продуктов (6 вариантов), отсортированные по возрастанию.
- **Активный чип** — выделяется фоном `accent` или `primary` в зависимости от категории, с иконкой `×`.
- **Кнопка "Wis filters"** — появляется только когда хотя бы один фильтр активен. Сбрасывает все фильтры.
- **Счётчик** `"X van Y variëteiten"` — обновляется реактивно при изменении фильтров.

### Мобильный вид

Чипы прокручиваются горизонтально (`overflow-x: auto`), строки не переносятся принудительно.
